# Arquitetura e estado atual

## Visão proposta
1. Interface web responsiva para os participantes.
2. Camada de aplicação para cadastro, solicitações, coletas e relatórios.
3. Serviço de dados com autenticação e controle de acesso.
4. Integrações futuras, se justificadas: mapas/geolocalização e notificações.

## Estado deste repositório
- `index.html`: página pública/portfólio acadêmico.
- `assets/logo-ecocoleta.png`: identidade visual.
- `pesquisa/`: relatório e indicadores da pesquisa exploratória.
- `docs/`: documentação do projeto.

## Limitações
Este pacote não contém backend, banco de dados, autenticação, GPS real ou sincronização. A arquitetura acima é uma visão de evolução, não uma descrição de funcionalidades já entregues.
