# Executar e publicar

## Visualização local
1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador.
3. Para publicar, mantenha a estrutura de pastas, pois os links são relativos.

## GitHub Pages
1. Crie um repositório público chamado `ecocoleta` (ou outro nome).
2. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e utilize o endereço apresentado pelo GitHub Pages.

## Antes de publicar
- Preencher equipe, instituição e câmpus.
- Conferir os dados e a metodologia da pesquisa.
- Adicionar evidências reais de entrevistas, testes ou validações, se realizadas.
- Atualizar a demonstração apenas quando houver uma versão testável.
